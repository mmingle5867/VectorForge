# Approval Name and Context v0.69.0

Final SVG, PNG, and JPG output names now derive from the immutable original asset filename, not from the active working JPG. For example, `BabyOnBoardFeet-edit-v0002.jpg` approves as `BabyOnBoardFeet.svg`, `BabyOnBoardFeet.png`, and `BabyOnBoardFeet.jpg`.

The Prepare / Vectorize Artwork header now identifies both:

- **Artwork name** — the immutable original filename that defines final output naming.
- **Editing now** — the currently selected original or working version.
